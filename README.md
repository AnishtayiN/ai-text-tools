# 🧠 AI Text Tools

مجموعه ابزارهای هوشمند متن و صدا — **کاملاً رایگان، بدون ثبت‌نام و بدون نیاز به سرور**

پروژه روی **GitHub Pages** میزبانی می‌شود:
👉 **[https://anishtayin.github.io/ai-text-tools](https://anishtayin.github.io/ai-text-tools)**

---

## ✨ قابلیت‌ها

| ابزار | توضیح |
|-------|--------|
| 🗣️ **متن به صدا** | تبدیل متن به گفتار با انتخاب صدا، زبان، سرعت و زیر و بمی (Web Speech API) |
| 🎤 **صدا به متن** | تشخیص گفتار زنده فارسی/انگلیسی/عربی و... با نتایج لحظه‌ای |
| 📝 **خلاصه‌سازی** | خلاصه هوشمند متن یا استخراج متن از URL + حالت آفلاین سریع |
| 📖 **گسترش متن** | تبدیل متن کوتاه/خلاصه به متن کامل و بلند با سبک‌های مختلف |

## 🎯 ویژگی‌های کلیدی

- **رایگان و بدون سرور** — همه‌چیز سمت مرورگر اجرا می‌شود
- **رابط فارسی RTL** با فونت وزیرمتن
- **تم تیره/روشن** با تشخیص خودکار سیستم
- **PWA** — قابل نصب روی گوشی و کامپیوتر + کارکرد آفلاین
- **۸ زبان** برای تبدیل صدا و تشخیص گفتار
- **دریافت متن از URL** با Jina Reader
- **کپی و دانلود** خروجی‌ها (txt/md)
- **میانبر `Ctrl+K`** برای فوکوس سریع

## 🛠️ تکنولوژی‌ها

- **Web Speech API** (تبدیل متن به صدا + تشخیص گفتار)
- **Jina AI Reader** (استخراج متن از صفحات وب)
- HTML5 + CSS3 + JavaScript خالص (بدون فریمورک)
- Service Worker (آفلاین + نصب PWA)

## 📁 ساختار پروژه

```
ai-text-tools/
├── index.html      # ساختار اصلی و ۴ تب
├── styles.css      # استایل‌های کامل
├── app.js          # منطق برنامه
├── sw.js           # Service Worker
├── manifest.json   # تنظیمات PWA
└── icon.svg        # آیکون
```

## 🚀 اجرای محلی

```bash
# فقط فایل index.html را باز کنید
# یا با یک سرور ساده:
python3 -m http.server 8000
# سپس: http://localhost:8000
```

## ⚠️ نکات مهم

- **تشخیص گفتار زنده** فقط در Chrome/Edge کار می‌کند و نیازمند اینترنت است
- **تبدیل متن به صدا** بسته به مرورگر، صداهای متفاوتی دارد (برای فارسی Chrome/Edge بهتر است)
- **خلاصه‌سازی هوشمند** از Jina Reader استفاده می‌کند؛ در نبود اینترنت، حالت سریع آفلاین فعال می‌شود
